# レトロ・クライマー

スマートフォンを縦に持って遊ぶ、8ビット風のドット絵の横スクロール・アクションゲーム。
7体のロボットから1体を選び、走って、跳んで、はしごを登って、ステージの最後にあるゴールの旗をめざす。

**遊ぶ：https://nakamuramakunouti14-glitch.github.io/retro-climber/**

ブラウザだけで動く。インストールやログインは要らない。
iPhone では Safari で開き、共有ボタンから「ホーム画面に追加」すると、アプリのように全画面で遊べる。

## 遊び方

- ◀ ▶：歩く
- ジャンプ：跳ぶ（長く押すと高く跳ぶ）
- ▲ ▼：はしごを登る・降りる
- ▼ を押しながらジャンプ：乗っている板から下りる
- Ⅱ：ひとやすみ（やり直し・ステージ選び・音のオン／オフ）
- パソコンでは、矢印キーで歩き、スペースキーで跳ぶ

ルール

- 敵は上から踏むとたおせる。横から当たるとハートが1つ減る
- 途中の旗にタッチすると、落ちたときやハートがなくなったときに、そこから再開できる
- 星のかけらを集めてゴールすると、集めた数が記録に残る（ブラウザの中に保存）
- ステージをクリアすると、次のステージが開く

### 7体のキャラクターと得意技

| 名前 | 見た目 | 得意技 |
|---|---|---|
| ムスビ | 赤いおにぎり | いちばん扱いやすい。足場のはしからでも跳びやすい |
| ピョコ | 水色のうさぎ | 高く跳べる |
| ピコ | 緑のテレビ | 足が速い |
| ポルチ | ミントのきのこ | 空中でジャンプを押し続けると、かさでゆっくり降りる |
| コロン | オレンジのたまご | 走りながら体当たりすると、敵をたおせる |
| プロロ | 紫のカプセル | 空中でもう1回跳べる |
| ナナ | 黄色のバナナ | ハートが1つ多い。足は少しおそい |

どのキャラクターでも、すべてのステージをクリアできるように作ってある。

### ステージ

1. そよかぜの草原：歩く・跳ぶ・はしごの練習
2. あかね屋根の港町：屋根から屋根へ跳び移る
3. くものうえの塔：はしごで下から上へ登っていく

## 作り

- 言語と部品：JavaScript、[Phaser 3](https://phaser.io/)（ゲームの部品）、[Vite](https://vite.dev/)（組み立て）、[Vitest](https://vitest.dev/)（テスト）
- 絵と音：画像ファイルや音声ファイルは使っていない。ドット絵は文字の並び（1文字が1ドット）からプログラムで描き、効果音と BGM は Web Audio でその場で鳴らす。曲もこのゲームのために作った
- キャラクター・絵・音楽・ステージはすべてオリジナル。雰囲気は1980年代の家庭用ゲーム機の横スクロール・アクションを参考にしたが、既存のゲームのキャラクター・絵・音楽・ステージは使っていない
- 縦持ちの画面：上半分をゲーム、下半分をボタンにして、指がゲーム画面にかからないようにした

```
src/
  main.js         全体の流れ（タイトル → キャラ選び → ステージ選び → 遊ぶ → クリア）
  StageScene.js   走る・跳ぶ・登る・敵・旗・ゴール
  characters.js   7体の絵（文字の並び）と得意技の数値
  stages.js       ステージの地図（1文字が1マス）と、地図の決まりのチェック
  textures.js     地面・はしご・背景などの絵をプログラムで描く
  controls.js     画面のボタン（指をすべらせても効く）とキーボード
  audio.js        効果音と BGM
  save.js         クリアと星の記録
  ui.js           メニュー画面と上の帯（ハート・星）
tests/            キャラ・ステージの地図・セーブのテスト
tools/            ホーム画面用アイコンを作るスクリプト
```

### 手元で動かす

```bash
npm install
npm run dev     # 開発用のサーバー
npm test        # テスト
npm run build   # 公開用に組み立てる（dist/ にできる）
```

公開は、`npm run build` でできた `dist/` の中身を `gh-pages` ブランチに置き、GitHub Pages で配信している。

## Claude Code での開発

このゲームは、AI のコーディング支援ツール [Claude Code](https://www.anthropic.com/claude-code) と一緒に作った。私はプログラマーではなく、何を作るかを決め、選び、遊んで確かめる役を担った。コードを書いたのは Claude Code である。

1. **要件を決める**：「縦持ちの iPhone で、昔のゲームのようなドット絵で、跳んだり登ったりするゲーム」という一言から始めた。Claude Code が選択式で質問し（遊び方・操作・置き場所・遊ぶ人・期限）、答えを仕様書にまとめた
2. **参考を調べる**：Claude Code が調査用のサブエージェント4つに、並行して調べものを任せた。テーマは、似た作品、作り方（ゲームの部品と置き場所）、ドット絵と音の作り方、縦持ちの横スクロールの工夫。結果は出典つきでまとめさせた
3. **デザインを選ぶ**：色・雰囲気・画面の分け方が違うラフ案を3つ作ってもらい、「上がゲーム、下がボタン」の案を選んだ。キャラクターは私がデザインしたロボットを元に、ドット絵にしてもらった。名前と得意技も相談して決めた
4. **作る**：仕様書の OK を出してから、Claude Code が Phaser と Vite で実装した
5. **確かめる**：Claude Code がテスト（ステージの地図の決まり・セーブ・キャラクターの絵）を書いて実行した。iPhone と同じ画面の大きさのブラウザで、歩く・跳ぶ・はしご・敵・ゴール・得意技を実際に動かして確かめた
6. **直す**：遊んでみて「キャラクターが上下にブルブル震えて見づらい」と伝えた。Claude Code は位置を毎フレーム測り、原因を2つ突き止めた
   - 歩くときの2コマ目で、体を1ドット沈めていた
   - 物理の計算の小さな誤差（128 と 127.99999…）が、描くときの切り捨てで1ドットの上下になっていた

   2つとも直し、同じことが起きないようにテストを足した

このゲームの開発では、Codex（OpenAI）は使っていない。

## 対応環境

- iPhone の Safari（縦向き）が主な対象。横向きにすると「縦に持ってね」と表示する
- パソコンのブラウザ（Chrome・Safari など）でも、キーボードで遊べる
- iPhone では、マナーモードのときに音が鳴らないことがある
